## 本章目标

建立独立运行的 `user-rpc`，将后续账号业务和 MySQL 访问放在该服务中，并逐步验证 API 到 RPC、RPC 到 MySQL 的调用链。每轮只实现其中一个小单元。

```text
浏览器或 curl
    ↓ HTTP
lab-api
    ↓ RPC
user-rpc
    ↓
MySQL
```

`lab-api` 接收外部 HTTP 请求；`user-rpc` 负责账号相关业务和数据访问。MySQL 是业务数据存储，不编写临时内存用户仓库。
